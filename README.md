# SimpleBilling

**Live app: https://simplebilling.mehedimaruf.com/**

SimpleBilling is a local-first billing tracker for small service businesses. Keep customers,
products and billing terms in one place, see who is prepaid, due or overdue, and send branded
PDF or PNG statements and payment receipts by email or WhatsApp. It runs entirely in the
browser: no server, no account, and your data stays on your device.

Author: Mehedi Maruf (BlesseDevil) — https://mehedimaruf.com

## About this repository

This repository holds only the published build of the app, served through GitHub Pages. It is
generated automatically on every release, so changes made here are overwritten. The source code
is not public.
